# hooks 候補（最小構成）

このディレクトリは初期フェーズの hooks 設計メモです。
実装前提ではなく、3人チームで過剰に重くしない最小運用を定義します。

## hard block（初期導入推奨）
- 危険なシェル操作の拒否（`rm -rf /`, `curl ... | bash`, 破壊的な権限変更）
- ADR未承認クラウド依存の新規追加（Firebase/GCP/Cloud Run/GCS）

## soft guard（初期導入推奨）
- `docs/specs/**` 変更時に ADR 0001 参照確認を通知
- `infra/**` 変更時に「未決定事項を確定していないか」確認を通知

## 今は入れない
- すべてのPRで強制的に重い静的解析/全文Lint
- 仕様書全量の自動整合判定（誤検知コストが高い）
